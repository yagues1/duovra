# Code of Conduct

Duovra follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. Harassment, personal attacks, discriminatory language and the publication of other people's private information aren't tolerated in any project space (issues, pull requests, discussions or any other channel).

## Reporting

To report unacceptable behavior, use GitHub's **Report content** option on the comment or issue, or contact the maintainer privately through the email listed on the maintainer's GitHub profile. Reports are handled confidentially.

The maintainer may remove, edit or reject contributions that don't follow this code, and may restrict participation in the project.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
