# Referencias visuales aprobadas

Esta carpeta está preparada para recibir las vistas del diseño conceptual ya aprobado. **Está vacía a propósito.**

No se han creado capturas ni imágenes generadas que simulen ser referencias originales. Cualquier imagen que aparezca aquí debe ser una captura real del diseño aprobado, aportada por el usuario.

## Vistas pendientes de incorporar

Se necesitan cinco vistas. Las cuatro primeras están descritas en el brief del proyecto:

| # | Vista | Descripción en el brief |
|---|---|---|
| 1 | Chat principal | Vista principal de conversación. |
| 2 | Proyectos | Gestión de proyectos. |
| 3 | Barra lateral flotante | Navegación en barra lateral flotante con efecto Liquid Glass. |
| 4 | Paneles contextuales | Paneles que aparecen según el contexto. |
| 5 | **Pendiente de definir** | El brief no indica la quinta vista. Hay que confirmarla con el usuario. |

## Formato esperado

- PNG, con la resolución original del diseño.
- Nombre: `01-chat-principal.png`, `02-proyectos.png`, `03-barra-lateral.png`, `04-paneles-contextuales.png`, `05-<nombre>.png`.
- Si hay estados (hover, foco, transición), una imagen por estado, en subcarpetas con el mismo número.
